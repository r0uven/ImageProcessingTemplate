# Development
Установите зависимости для 2 директорий: общей папки и папки с фронтэндом командой npm install
## Запуск в режиме разработки

Запустите оба приложения в отдельных терминалах.

### Backend

```bash
cd backend //если в общей папке
uvicorn main:app --reload
```

### Frontend (Tauri)

```bash
cd frontend
npm run tauri dev
```
Или можно запустить из общей папки:

через pm2(мощный инструмент):

Запуск: pm2 start ecosystem.config.js

Просмотр логов: pm2 monit или pm2 logs

Остановка: pm2 delete all

через простой самописный скрипт:
npm run dev

# Работа с миграциями базы данных

Настройка и инициализация базы данных находится в файле:

```text
frontend/src-tauri/src/lib.rs
```

## Если изменяется существующая миграция

После изменения существующей миграции необходимо удалить локальную базу данных:

```text
.../AppData/Roaming/com.tauri.dev/database.db
```

После следующего запуска приложение создаст базу заново и применит все миграции.

---

## Если не хочется удалять базу данных

Вместо удаления базы рекомендуется создать новую миграцию.

1. Увеличьте номер версии:

```rust
Migration {
    version: 2,
    description: "insert_default_tool",
    // ...
}
```

2. Добавьте новую миграцию в список:

```rust
vec![
    migration_1(),
    migration_2(),
]
```

> После того как новая миграция была применена при первом запуске приложения, любые последующие изменения следует оформлять уже **новой** миграцией с новой версией. Не изменяйте миграции, которые уже были выполнены.
